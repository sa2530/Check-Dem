# Check-Dem — Dashboard ค่าตู้ขาเข้า HEUNG A

Dashboard คำนวณ Demurrage (DEM), Detention (DET) และค่าไฟ Reefer (ELE) ของตู้ขาเข้า
พิมพ์เลข B/L หรือเลขตู้ เลือกวันออกของ แล้วดูผลตามขั้นบันไดและตามประเภท/ขนาดตู้

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเข้ารหัสด้วยรหัสผ่าน (AES-256) สำหรับ GitHub Pages ข้อมูลจริงอยู่ในรูปข้อความเข้ารหัส ถอดรหัสในเบราว์เซอร์ผู้เปิดเท่านั้น |
| `encrypt_dashboard.js` | เข้ารหัส `dashboard.html` (ไฟล์จริงบนเครื่อง ไม่ถูก push) เป็น `index.html` |
| `set_dashboard_password.ps1` | ตั้งรหัสผ่านเข้ารหัส (เก็บใน `dashboard.pw` ไม่ถูก push) |
| `refresh_portal_data.py` | ดึงข้อมูลจาก SVMS portal API (DEM/DET report [04] [05] และ `bl info`) แล้วเขียนทับข้อมูลใน `index.html` |

## การอัปเดตข้อมูล

ต้องรันบนเครื่องที่มีชุดเครื่องมือ SVMS API ของสำนักงาน (`SinokorAPI\Thailand_HEUNG-A`) และคีย์ของสำนักงาน
**คีย์ API ไม่ได้อยู่ใน repo นี้และห้ามใส่เข้ามา**

```
python refresh_portal_data.py
```

บนเครื่องตั้งให้รันอัตโนมัติด้วย Windows Task Scheduler ทุกวัน 08:00 และหลังเปิดเครื่อง
(ดู `refresh.log` สำหรับผลการรัน ไฟล์นี้ไม่ถูกเก็บใน repo)

## หมายเหตุ

- ข้อมูลเป็นภาพ ณ วันที่ดึง (แสดงบนหน้าเว็บ) ถ้าเก่ากว่าวันนี้ หน้าจะขึ้นแถบเตือน
- ยอด "Amount" มาจาก portal (คิดตาม tariff ของ B/L) ส่วนยอด "คำนวณ" ใช้ตารางอัตราขั้นบันไดของหน้านี้
- ข้อมูลจริง (ชื่อลูกค้า เลข B/L ยอดค่าใช้จ่าย) ไม่อยู่ใน repo ในรูปที่อ่านได้ มีเฉพาะข้อความเข้ารหัส ความปลอดภัยขึ้นกับความยาวและความไม่ซ้ำของรหัสผ่าน
